## How this is scored

* 1,000 texts are drawn with a fixed seed from the test and validation splits.
* Each is passed to `redact()` without logging; only the redacted text is scored.
* A PII value is an annotation of one of the nine domains with at least 3 letters or digits.
* It has leaked when 3 or more of them are still readable. The marker type is ignored: a name covered by `[[USERNAME]]` is not a leak.
* Gretel does not annotate file paths, so FILEPATH is not measured.
